# Publicação e direitos

Este projeto é uma iniciativa de preservação/engenharia/localização independente. Um repositório público não deve receber automaticamente material cuja redistribuição possa envolver direitos de terceiros.

## Não incluir automaticamente

- XEXs (`sm64*.xex`, builds 60 FPS etc.).
- ZIPs que embutam XEX ou arte de Nintendo.
- imagens mapeadas, `text.raw`, `text.elf` e disassemblies extraídos de binários do jogo.
- `dialogs.h`, dumps de diálogos/textos originais ou assets extraídos.
- capas e screenshots com arte/personagens/logotipos proprietários.
- ROMs, caso apareçam futuramente.

## Pode compor o candidato público após revisão

- documentação original deste projeto;
- mapeamento de controles escrito pelo projeto;
- histórico de engenharia em forma de descrição factual;
- scripts próprios, somente após revisão individual para garantir que não incorporem material/segredos de terceiros.

Nenhuma senha, token ou credencial foi incluída no pacote de migração.
